# Used Items Marketplace

A simple web application for buying and selling used items using Node.js, Express.js, and MongoDB.

## Features
- View available items
- Add new items for sale
- Buy listed items
- Store data in MongoDB
- Responsive user interface

## Technologies Used
- HTML, CSS, JavaScript
- Node.js
- Express.js
- MongoDB

## How to Run
1. Install dependencies using `npm install`.
2. Start MongoDB.
3. Run the server using `npm start` or `node server.js`.
4. Open `http://localhost:3000` in your browser.
