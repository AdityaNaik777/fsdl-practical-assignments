# HTML Formatting Tags Reference

This project is a simple HTML webpage that demonstrates various HTML text formatting tags.

## Features
- Displays common HTML formatting tags
- Description and live example for each tag
- Clean and responsive user interface
- Green-themed modern design
- Animated header icon
- Downloadable HTML cheat sheet

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any web browser.
3. Explore the formatting tags and their examples.
4. Click the download button to save the cheat sheet.
