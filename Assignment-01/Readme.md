# Assignment 01 - HTML Formatting Tags Reference

## Objective
The objective of this assignment is to demonstrate the use of various HTML text formatting tags by creating a responsive and visually appealing reference page.

## Description
This project showcases commonly used HTML formatting elements along with their descriptions and live examples. It is designed as an easy-to-use cheat sheet for beginners learning HTML.

## Features
- Responsive and modern UI using HTML5 and CSS3
- Comprehensive table of HTML formatting tags
- Live visual examples for each formatting tag
- Hover effects and attractive green theme
- Animated header icon using CSS animations
- Downloadable HTML formatting cheat sheet (.txt)
- Clean and structured code

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome Icons

## How to Run
1. Open the project folder.
2. Double-click `index.html` or open it using Live Server.
3. Explore the HTML formatting tags and examples.
4. Click the **Download Full Cheat Sheet** button to download the reference.
