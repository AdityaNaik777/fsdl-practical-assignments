# Weather Analytics Dashboard

A simple interactive weather dashboard built using HTML, CSS, JavaScript, and Chart.js.

## Features
- Display weather statistics
- Interactive line and bar charts
- Select city and date range
- Dynamic data updates
- Responsive dashboard design

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js

## How to Run
1. Open `index.html` in a web browser.
2. Select a city and date range.
3. Click **Simulate New Data** to refresh the charts.
